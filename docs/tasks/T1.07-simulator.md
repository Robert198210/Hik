# T1.07 — Device simulator with Digest authentication and fault profiles

Role: Developer (Auto Cost). Risk: Medium. Prerequisites: T1.05, T1.06.
References: ADR-008.

## Files
- `src/haca/simulation/digest.py`: minimal RFC 7616 server side.
  - `WWW-Authenticate: Digest realm="HACA-SIMULATED", qop="auth", nonce=..., algorithm=MD5`
  - verifies `response` for `qop=auth`
  - per-device nonces
  - rejects a stale or unknown nonce with 401
- `src/haca/simulation/device.py`: `SimulatedDevice(device_id, profile_dir: Path, username: str,
  password: str, faults: FaultProfile)`.
- `src/haca/simulation/network.py`: `SimulatedNetwork(devices: dict[tuple[str, int], SimulatedDevice])`
  with `.transport() -> httpx.MockTransport` and `.request_log: list[(device_id, method, path)]`.
- `src/haca/simulation/faults.py`: `FaultProfile` (frozen):
  - `auth_always_fail: bool`
  - `connect_error: bool`
  - `read_timeout_times: int`
  - `http_status_override: dict[path, int]`
  - `not_support_paths: set[str]`
  - `malformed_paths: set[str]`
- `tests/integration/test_simulator.py` (marker `simulation`).

## Behaviour
- Unknown `(host, port)` → `httpx.ConnectError`.
- Any method other than GET → HTTP 405. This is a second line that makes guard bypasses visible in tests.
- A path not in `index.yaml` → HTTP 404 with body from `shared/edge-cases/response_status_url_not_found.xml`.
- A path in `not_support_paths` → HTTP 200 with the `notSupport` ResponseStatus body.
- Responses use `Content-Type: application/xml; charset="UTF-8"`.
- Credentials for simulation come from `EnvCredentialStore`-compatible values `synthetic` / `synthetic-pass`.
  Never use real-looking passwords.

## Acceptance criteria
1. `IsapiClient` → simulator → `read("system.device_info")` succeeds for nvr01, ptz01, cam01 through the
   full `ReadOnlyTransport` chain, with Digest.
2. The wrong password → `AuthError`.
3. Each fault profile maps to the expected `IsapiError` subclass:
   - `connect_error` → `DeviceConnectionError`
   - `read_timeout_times=3` → `DeviceTimeout`
   - `not_support_paths` → `NotSupportedError`
   - unknown path → `EndpointNotFound`
   - `malformed_paths` → `XmlParseError`
4. `request_log` shows only `GET` entries after any test run of the client.
5. With a bypass test that sends `PUT` through the raw `MockTransport` (no guard), the simulator returns 405.
