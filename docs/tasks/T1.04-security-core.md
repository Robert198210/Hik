## EndpointPolicy
- `EndpointRule` (frozen):
  - `id`, `path_template`, `method: Literal["GET", "POST"]`, `read_post: bool = False`
  - `allowed_query: frozenset[str] = frozenset()`
  - `sensitivity: Literal["normal", "sensitive", "denied"]`
  - `post_root_elements: frozenset[str] = frozenset()`
- Path template placeholders `{channel}`, `{id}`, `{track}` compile to `[0-9]{1,5}`. The match is
  anchored to the full path and is case-sensitive.
- `EndpointPolicy(rules: list[EndpointRule])`. `EndpointPolicy.authorize(method: str, raw_path: str,
  query: str, body: bytes | None) -> EndpointRule` runs these checks in order and raises
  `PolicyViolation` on the first failure:
  1. Raw path hygiene. Reject non-ASCII, NUL, `\`, `//`, `/./`, `/../`, a trailing `/..`, and any `%`
     sequence decoding to `.`, `/`, `\` or NUL (`%2e`, `%2f`, `%5c`, `%00`, case-insensitive).
     Reject double encoding (`%25`).
  2. Denylist, case-insensitive, on the decoded path. Patterns are listed in
     [isapi-endpoint-registry.md](../isapi-endpoint-registry.md#denylist-path-patterns-method-independent).
     The denylist overrides any rule.
  3. Match a rule. No match → `not_allowlisted`. `sensitivity == "denied"` → `denied_endpoint`.
  4. Method:
     - `GET` requires `rule.method == "GET"`.
     - `POST` requires `rule.read_post` and a body that parses with `defusedxml` and whose root local
       name is in `post_root_elements`.
     - Every other method (PUT, DELETE, PATCH, HEAD, OPTIONS, …) → `method_not_allowed`.
  5. Query keys must be a subset of `allowed_query`.
- `EndpointPolicy.render(endpoint_id, **params) -> str` returns the path. Params must be ints within
  the placeholder range; unknown or missing params raise.

## ReadOnlyTransport
- `ReadOnlyTransport(inner: httpx.BaseTransport, registry: DeviceRegistry, policy: EndpointPolicy,
  egress: EgressPolicy)` implements `httpx.BaseTransport.handle_request`.
- For **every** request, including Digest retries, it checks:
  - `egress.check(url)`
  - `registry.match(host, port, scheme)` is not `None`
  - `policy.authorize(...)`

  Only then does it delegate to `inner`.
- It denies requests that carry an `Upgrade` header. A `Cookie` header is allowed, because Digest
  retries may carry cookies from the 401 response, but it is never logged.
- Violations raise `PolicyViolation` and emit one log record `haca.security` at WARNING, with
  `reason_code`, method and path only.

## EgressPolicy
- `EgressPolicy(device_hosts: set[IPv4Address], allow_gemini: bool = False)`.
- Allowed destinations:
  - device hosts
  - `generativelanguage.googleapis.com` over https:443, only when `allow_gemini`
- Everything else raises `PolicyViolation("egress_denied")`.

## Redaction
- `redact_text(text: str) -> str` masks:
  - `Authorization:` header values
  - Digest `response=`, `nonce=`, `cnonce=` values
  - key/value pairs for `password|passwd|pwd|secret|token|apikey|api_key`
  - `AIza[0-9A-Za-z_-]{35}`
  - values registered via `register_secret(value)`
- `SecretRedactor(logging.Filter)` applies it to `record.msg` and `record.args`.
- `install_redaction()` adds the filter to every handler of the root logger. It is idempotent.

## Credentials
- `Credential(username: str, password: SecretStr)`. `repr` and `str` never show the password.
- `CredentialStore` Protocol with `get(credential_ref: str) -> Credential`.
- `KeyringCredentialStore(service="haca")` reads the keys `<ref>:username` and `<ref>:password`.
  Missing keys raise `CredentialNotFound(ref)`.
- `EnvCredentialStore` reads `HACA_CRED_<REF>_USERNAME` and `HACA_CRED_<REF>_PASSWORD` (ref upper-cased).
- Every password loaded from a store is passed to `register_secret`.
- Write methods are not implemented. HACA never stores credentials in v1 setup code, and Phase 1
  tests use `EnvCredentialStore` or a fake keyring backend.

## Acceptance criteria (tests in `tests/security/`, marker `security`)
1. Method matrix: for a GET rule, `PUT`, `DELETE`, `PATCH`, `HEAD`, `OPTIONS`, `POST` → `method_not_allowed`.
2. Denylist precedence: a rule that deliberately allows each of the following is still rejected by the
   denylist:
   - `/ISAPI/System/reboot`
   - `/ISAPI/System/factoryReset`
   - `/ISAPI/System/updateFirmware`
   - `/ISAPI/System/configurationData`
   - `/ISAPI/PTZCtrl/channels/1/continuous`
   - `/ISAPI/PTZCtrl/channels/1/presets/1/goto`
   - `/ISAPI/ContentMgmt/Storage/hdd/1/format`
   - `/ISAPI/Security/users`
   - `/ISAPI/System/activate`
   - `/SDK/x`
   - `/PSIA/x`
   - `/cgi-bin/x`
3. Bypass attempts are rejected:
   - `/ISAPI/System/%2e%2e/reboot`
   - `/ISAPI//System/reboot`
   - `/ISAPI/System/REBOOT`
   - `/ISAPI/System/deviceInfo/../reboot`
   - `%252e`
   - non-ASCII characters
   - unknown query key
4. Transport:
   - foreign host, public IP, wrong port, wrong scheme, hostname → rejected before `inner` is called
     (assert with a counting inner transport)
   - a Digest 401 → retry pair is checked twice
5. Canary: with password `CANARY-PW-7f3a` loaded via `EnvCredentialStore`, run a failing request flow
   and log at DEBUG. The string appears neither in `caplog.text` nor in any `PolicyViolation.detail`.
6. `test_dependencies.py`: parse `pyproject.toml` runtime deps and `importlib.metadata` distributions of
   the venv. Fail if any name matches `anthropic|openai|cursor.*|claude.*`.
7. `mypy --strict` clean for `haca.security`. Branch coverage ≥ 95 % for `endpoint_policy.py` and
   `transport_guard.py`.
