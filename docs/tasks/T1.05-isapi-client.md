## XML (`xml.py`)
- `parse_xml(body: bytes, max_bytes: int = 5_000_000) -> XmlDocument`.
  - Uses `defusedxml.ElementTree.fromstring` with `forbid_dtd=True`, `forbid_entities=True`,
    `forbid_external=True`.
  - Strips a leading UTF-8 BOM and surrounding whitespace.
  - Over the size limit, or on any defusedxml/ParseError → `XmlParseError`. The message holds no body
    content beyond 80 characters.
- `XmlDocument`:
  - `root_tag` (local name), `namespace: str | None`, `version: str | None` (root `version` attribute)
  - `text(path: str) -> str | None`: slash-separated local names relative to the root, e.g.
    `"firmwareVersion"`, `"sourceInputPortDescriptor/ipAddress"`
  - `elements(path) -> list[XmlElement]`
- Namespace-agnostic: the same queries work with namespace `http://www.hikvision.com/ver20/XMLSchema`,
  `http://www.isapi.org/ver20/XMLSchema`, or none, and with root `version="1.0"` or `"2.0"`.

## ResponseStatus (`response_status.py`)
- `ResponseStatus(request_url: str | None, status_code: int | None, status_string: str | None,
  sub_status_code: str | None, description: str | None)`.
- `parse_response_status(doc: XmlDocument) -> ResponseStatus | None` returns `None` when the root is not
  `ResponseStatus`.
- `is_success`: `status_code == 1` or `sub_status_code == "ok"`.

## Errors (`errors.py`)
- Base `IsapiError(device_id, endpoint_id)`. Subclasses:
  - `AuthError`
  - `EndpointNotFound`
  - `NotSupportedError`
  - `DeviceReportedError(status_code, sub_status_code)`
  - `DeviceTimeout`
  - `DeviceConnectionError`
  - `XmlParseError`
  - `UnexpectedStatus(http_status)`
- `PolicyViolation` from `haca.security` propagates unchanged. It is never caught and converted.

## IsapiClient (`client.py`)
- Constructor arguments:
  - `device: ResolvedDevice`, `credential: Credential`
  - `registry: DeviceRegistry`, `policy: EndpointPolicy`, `egress: EgressPolicy`
  - `timeouts: TimeoutConfig`
  - `inner_transport: httpx.BaseTransport | None = None`
  - `sleep: Callable[[float], None] = time.sleep`
- It builds `httpx.Client` with:
  - `transport=ReadOnlyTransport(inner or httpx.HTTPTransport(retries=0), ...)`
  - `auth=httpx.DigestAuth(...)`
  - `follow_redirects=False`
  - `timeout=httpx.Timeout(connect=..., read=..., write=5, pool=5)`
  - header `Accept: application/xml`
  - `trust_env=False`, so no proxies from the environment
- Basic auth is not supported in Phase 1.
- `read(endpoint_id: str, **params: int) -> IsapiResponse` returns
  `IsapiResponse(device_id, endpoint_id, path, http_status, content_type, body, sha256, elapsed_ms,
  document, response_status)`.
- Mapping order:
  1. If the body parses as `ResponseStatus`:
     - `sub_status_code == "notSupport"` → `NotSupportedError`
     - `"RequestUrlNotFound"` → `EndpointNotFound`
     - any other non-success → `DeviceReportedError`
  2. If HTTP status is 401 or 403 → `AuthError`.
  3. If HTTP status is 404 → `EndpointNotFound`.
  4. Any other non-2xx, including 3xx → `UnexpectedStatus`.
  5. On 2xx with an XML content type or a body starting with `<` → parse into `document`.
     Otherwise `document=None`.
- Retry, at most 2 extra attempts with backoff 0.5 s and 1.0 s via `sleep`:
  - only on `httpx.ConnectError`, `httpx.ConnectTimeout`, `httpx.ReadTimeout`, and HTTP 502/503/504
  - never on 401/403/404, other 4xx, `PolicyViolation`, or parse errors
- After retries are exhausted → `DeviceTimeout` or `DeviceConnectionError`.
- Context manager closes the client. No logging of bodies above DEBUG. Never log headers.

## Acceptance criteria (via `httpx.MockTransport`, no real network)
1. A 200 `DeviceInfo` body parses, and `doc.text("model")` works for all three namespace variants.
2. 200 or 403 with a `ResponseStatus`/`notSupport` body → `NotSupportedError`. With
   `RequestUrlNotFound` → `EndpointNotFound`.
3. Digest flow:
   - a 401 challenge followed by 200 succeeds
   - invalid credentials → `AuthError`
   - the inner transport is called exactly 2 times (no retry loop)
4. A 302 with `Location: http://8.8.8.8/` → `UnexpectedStatus`. The redirect target is never requested.
5. Retry behaviour:
   - `ReadTimeout` twice then 200 → success with 2 sleeps (0.5, 1.0)
   - `ConnectError` three times → `DeviceConnectionError`
   - 500 → `UnexpectedStatus` without retry
6. An XXE payload (`<!DOCTYPE … SYSTEM "file:///etc/passwd">`) and a billion-laughs payload →
   `XmlParseError`. A body over 5 MB → `XmlParseError`.
7. `read("unknown.id")` and a policy-denied endpoint raise before any transport call.
8. `mypy --strict` clean for `haca.isapi`.
