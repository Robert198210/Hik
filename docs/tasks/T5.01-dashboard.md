# T5.01 — Local dashboard (v0.3)

Role: Developer (Auto Cost). Risk: Medium. Prerequisite: T4.01. References: ADR-006 (amended: no htmx,
vanilla JS only, no external assets).

## Files
- `src/haca/web/app.py`: `create_app(settings) -> FastAPI`
- `src/haca/web/routes.py`, `src/haca/web/tasks.py`, `src/haca/web/security.py`
- `src/haca/web/templates/*.html` (Jinja2), `src/haca/web/static/app.css`, `src/haca/web/static/app.js`
- CLI `haca serve [--port 8765] [--simulate]`
- tests in `tests/unit/web/`, using FastAPI `TestClient`

## Security
- `haca serve` binds `127.0.0.1` only. There is no `--host` option.
- Middleware:
  - reject requests whose `Host` header is not `127.0.0.1:<port>` or `localhost:<port>` (DNS rebinding)
  - POST requires a CSRF token: random per process, embedded in forms, checked with
    `secrets.compare_digest`
  - POST requires an `Origin` matching the host when present
- No device credentials and no Gemini key are ever rendered. The key form writes to keyring only and
  shows "configured / not configured".
- Response headers: `Content-Security-Policy: default-src 'self'`, `X-Frame-Options: DENY`,
  `Referrer-Policy: no-referrer`.

## Pages
- `/`: inventory (devices from config, last identification status), "Test connection" (POST runs
  identify for one device), last audit summary.
- `/audits/new` (POST): starts an audit in a background thread (`tasks.py`, one audit at a time) and
  redirects to `/audits/<run_id>`.
- `/audits/<run_id>`: progress (polled by `app.js` via `GET /api/audits/<run_id>/progress` JSON every
  1 s), then findings grouped by severity, a needs-decision panel, the coverage matrix, and manual
  checks.
- `/audits/<run_id>/report.{html,json,md}`: downloads.
- `/history`: list of runs. `/diff?a=&b=`: snapshot diff table.
- `/requirements`: ORP editor form generated from the ORP model enums.
  - Validate with the Pydantic model.
  - On save, write `config/requirements.yaml` and keep a timestamped backup in `config/backups/`.
  - Show the hash.
- `/settings`: read-only view of the subnet and devices, AI enabled/model, Gemini key status, and
  set/clear the key (keyring).
- Every page shows a `SIMULATED` banner when running with `--simulate`.

## Acceptance criteria
1. The app factory works with `TestClient`. All pages render in simulation mode.
2. POST without CSRF → 403. A foreign `Host` header → 400. `Origin` mismatch → 403.
3. An audit started via POST completes in simulation. The progress endpoint reaches `done`. Report
   downloads match the CLI outputs (same JSON schema).
4. The ORP editor rejects invalid enum values. A valid save writes the file and a backup, and the hash
   changes.
5. The rendered HTML contains no serials, MACs, usernames, or keys (scanner over all pages).
6. `serve` refuses to start if the port is in use, with a clear message. No `--host` option exists
   (test via argparse).
