# T6.01 — Optional browser inspection framework (v0.4)

Role: Developer (Auto Cost). **Risk: High → gate S4.** Prerequisite: T5.01. References: ADR-014, B7.

## Scope note
HAR capture from real devices is deferred (B7). This task builds the enforcement framework and
tooling. With no reviewed policy file, browser inspection refuses to run. Real page scripts are added
only after a user-captured, locally redacted HAR has been reviewed.

## Files
- `src/haca/browser/policy.py`: `BrowserPolicy` from `config/browser_policy.yaml`
- `src/haca/browser/proxy.py`: enforcing forward proxy (asyncio, stdlib only)
- `src/haca/browser/session.py`: state machine
- `src/haca/browser/inspector.py`: Playwright driver, extra `[browser]`
- `src/haca/browser/manual.py`: manual checklist → attestation YAML
- `tools/redact_har.py`
- `config/browser_policy.example.yaml`: empty pages, with comments
- tests in `tests/unit/browser/`, `tests/security/test_browser_proxy.py`; Playwright tests use marker
  `browser`, skipped when Chromium is not installed

## BrowserPolicy
- `devices: [device_id]`
- `allowed_get: [path regex]`
- `login_exceptions: [{method, path_regex, max_body_bytes}]`, valid only in state `LOGIN`
- `heartbeat_exceptions: [{method, path_regex}]`, valid in `AUTHENTICATED`
- `pages: [{id, url_path, extract: [{setting_id, selector, attribute|text}]}]`
- `reviewed_by`, `reviewed_at`, `har_sha256`

Load rules:
- refuse if `reviewed_by`/`reviewed_at` are missing
- refuse if any `allowed_get` or exception path matches the ISAPI denylist (T1.04)
- `pages` is empty in the example file

## Proxy (`proxy.py`)
- `EnforcingProxy(policy, registry, session)` listens on `127.0.0.1:<ephemeral>`.
- Plain HTTP: parse the request line and headers. Allow only if:
  - host:port is a registered device in the policy
  - method + path is allowed for the current session state
  - no `Upgrade` header
  
  Otherwise respond 403 and record a violation, which aborts the inspection.
- The checks run on every request, so redirect hops, Service Worker fetches, prefetches, and popups are
  all covered, because Chromium routes everything through the proxy.
- `CONNECT`: allowed only to a registered device host:port. The session is marked `reduced_assurance`
  (method/path not visible), and the report shows it.
- Decisions are logged as method, host, path, decision. Never headers or bodies.

## Session (`session.py`)
- States: `INIT → LOGIN → AUTHENTICATED → CLOSED`.
- Login is **manual**: the user types credentials in the headed browser. HACA never fills credential
  fields.
- Transition to `AUTHENTICATED` when the user confirms in the CLI, or when a configured success URL
  pattern is reached.
- Any violation → `CLOSED` and the browser is closed.

## Inspector (`inspector.py`)
- Launch Chromium with:
  - `proxy={"server": "http://127.0.0.1:<port>"}`
  - `args=["--proxy-bypass-list=<-loopback>", "--disable-features=NetworkPrediction"]`
- New context with:
  - `service_workers="block"`, `accept_downloads=False`, `permissions=[]`
  - `context.route("**/*")` re-checking the same policy as a second layer
  - WebSockets blocked (`context.route_web_socket` when available; the proxy also rejects `Upgrade`)
  - popups closed on creation
- Visit only the policy `pages`. For each, read the extract selectors (DOM read only) and save a
  screenshot to `live-results/browser/`. Results become coverage `VERIFIED_BROWSER` with tier `browser`.
- No generic click/type API exists in the module.

## Manual checklist (`manual.py`)
`haca manual checklist [--out PATH]` asks for each manual catalog item: value / not checked, plus an
optional screenshot path. It writes the attestation YAML used by `haca audit --manual`.

## HAR redaction tool (`tools/redact_har.py`)
- Runs locally only. Input HAR → output redacted HAR + `endpoints.txt` (unique method + path list).
- Removes:
  - all cookies and `Set-Cookie`
  - `Authorization`, `WWW-Authenticate`
  - query and body params matching `pass|pwd|token|nonce|session|challenge|salt|key`
    (case-insensitive)
  - request/response bodies of login/session endpoints
- Replaces serials, MACs, UUIDs, and non-subnet IPs with synthetic placeholders.
- Fails (non-zero exit) if any residual match of the secret patterns remains.
- Never uploads anything.

## Acceptance criteria
1. Proxy tests with a local stdlib HTTP test server. Each of these is blocked and aborts the session:
   - GET to a non-allowed path
   - POST outside `LOGIN`
   - redirect to a foreign host (follow-up request blocked)
   - WebSocket upgrade
   - request to a non-device host
   - `CONNECT` to a foreign host
2. A login exception is accepted in `LOGIN` and rejected in `AUTHENTICATED`.
3. A policy without review metadata, or containing a denylisted path, fails to load.
   `haca browser inspect` without a policy exits with a clear "no reviewed policy" message.
4. `redact_har.py` removes every planted secret from a synthetic HAR fixture and exits non-zero on a
   crafted residual.
5. Playwright smoke test (marker `browser`, skipped without Chromium): against a local test server via
   the proxy, a Service Worker registration does not take effect and no request bypasses the proxy
   (the proxy log contains every request seen by the server).
