# T1.06 — Synthetic fixtures, provenance, fixture secret scanner

Role: Developer (Auto Cost). Risk: Medium. Prerequisite: T1.01. Can run in parallel with T1.02–T1.05.
References: ADR-007, ADR-017 (**synthetic only**).

## Hard constraint
Do **not** open, read, copy, or derive values from any file under `/var/fpwork/ambrosew/skrypty/Hikvision/`
or any other real device capture. Author every fixture from generic ISAPI structure knowledge with
fictional values. When you are unsure whether an element exists on real firmware, leave it out.

## Acceptance criteria
1. Every profile directory has `provenance.yaml` with `origin: synthetic`.
2. The scanner reports 0 findings on the repo and ≥ 1 finding per violation class on the negative samples.
3. No value in any fixture resembles a real serial number, MAC, or non-test IP. Verified by the scanner.
4. `cam01` is identified as synthetic in its provenance and nowhere claimed as validated.
