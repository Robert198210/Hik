# T2.03 — SQLite snapshot store and snapshot diff

Role: Developer (Auto Cost). Risk: Medium (S2 scope). Prerequisite: T2.02. References: ADR-005.

## Files
- `src/haca/store/db.py`, `src/haca/store/models.py`, `src/haca/store/repositories.py`, `src/haca/store/diff.py`
- `tests/unit/test_store.py`, `tests/unit/test_diff.py`

## Schema (SQLAlchemy 2.0 declarative, SQLite)
- Schema version via `PRAGMA user_version = 1`. `open_db(path)` creates the tables and sets the version.
  A higher version raises.
- Tables:
  - `audit_runs`: id (uuid str), started_at, finished_at, simulated, scenario, haca_version, orp_hash,
    catalog_version, status, `kind = collect|audit`
  - `run_devices`: run_id, device_id, role, model, firmware, identity_status
  - `raw_responses`: run_id, device_id, endpoint_id, path, outcome, http_status, sub_status_code, sha256,
    body_gz (BLOB, gzip), collected_at, elapsed_ms
  - `settings`: run_id, device_id, endpoint_id, path, value. These are the flattened leaves from the
    normalizer.
  - `coverage`: run_id, device_id, setting_id, status, reason, evidence_tier, endpoint_id
  - `findings`: run_id, finding_id, rule_id, classification, severity, payload_json. Filled in T3.
- Indexes on `(run_id, device_id)`.
- Body storage: store gzip of the raw body. Never store request headers or credentials. Raw bodies may
  contain serial numbers and stay local; reports mask them (T3.02).
- Default DB path from `AppConfig.database_path`. Simulation uses `data/haca-sim.db` by default, so
  simulated and live runs are never mixed in one DB.

## Repositories
- `save_collection(session, result, *, orp_hash, catalog_version, scenario) -> run_id`
- `save_coverage(session, run_id, entries)`
- `list_runs(session, limit=20)`
- `load_run(session, run_id)`
- `load_settings(session, run_id) -> dict[(device_id, path), value]`

## Diff
`diff_runs(a, b) -> SnapshotDiff(added, removed, changed: list[(device_id, path, old, new)])`. The diff
ignores volatile paths matching configurable patterns; the default is `*.localTime`, `*.freeSpace`, `*.online`.

## CLI
- `haca collect` persists the result and prints `run_id`.
- `haca runs list`
- `haca diff RUN_A RUN_B [--json]`

## Acceptance criteria
1. Round trip: save a simulated collection and load it. Settings and coverage are equal. The gzip body
   decompresses to the original sha256.
2. `PRAGMA user_version` is 1. Opening a DB with version 99 raises a clear error.
3. A diff between `scenario-clean` and `scenario-conflicts` runs reports the ONVIF protocol change on
   nvr01 channel 1 and ignores `localTime`.
4. No column or blob contains the simulated password (canary test over the raw DB file bytes).
5. Simulated runs are written to `data/haca-sim.db` unless `--db` is given.
