# T1.10 — Security gate S1

Role: Security reviewer (Opus 5.5 chat) or Architect. Prerequisite: T1.09 verdict PASS.

## Scope
`haca.security`, `haca.isapi`, `haca.devices`, `haca.config` (secret handling), `haca.simulation`
(no real data), `tools/scan_fixture_secrets.py`.

## Checklist
- [ ] L1: the only request API is `IsapiClient.read(endpoint_id, **int_params)`.
- [ ] L2: the denylist is applied before the allowlist on the decoded path; traversal and encoding are
  rejected; POST is restricted to `read_post` rules with a root-element check.
- [ ] L3: the guard runs for every request, including Digest retries; `follow_redirects=False`;
  `trust_env=False`.
- [ ] Network policy is RFC1918-only, uses exact host matching, and allows loopback only in simulation.
- [ ] Egress: there is no other HTTP client in `src/`; Gemini host is disabled by default.
- [ ] Credentials:
  - no secret fields in config schemas
  - `Credential` repr is masked
  - redaction filter installed by the CLI
  - canary test present
- [ ] Fixtures: synthetic-only provenance; scanner green; no references to private paths.
- [ ] Dependencies: no non-Gemini AI packages.
- [ ] Residual risks recorded.

## Output
The verdict row in `docs/security-review.md` and findings with file:line.
